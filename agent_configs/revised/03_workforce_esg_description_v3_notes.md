스키마 description 문자열13곳만 수정했다. 기존19개 필드의 이름·순서·타입·배열 구조, [E###] 사실 및 근거 문자열 형식, 메타데이터·Agent/config 식별자·workflow 설정·schemaLayout·문서 파싱 설정은 원본 그대로다. 원본 export 메타데이터가 보존된 것은 형식 유지이며 현재 .env 연결이나 원격 Agent를 변경한 것이 아니다.

## 보완 사항

- ESG 최대8개 제한 안에서 중대재해·사망/중상·제재·환경/노동/인권 문제 등 중요한 부정적 사실을 인증·일반 정책보다 우선한다. 같은 정책은 묶고, 중요 사실을 담지 못한 제한은 명시한다.
- 사고장소만 근무지로 옮기고 사고를 버리지 않게 했다. 사고일/보고일/치료 후 사망일·피해·조치·조사 상태를 구분하고 미확정 사안을 법 위반 확정으로 표현하지 않는다.
- 배출량/에너지 단위, Scope와 조직 범위, 측정연도, 예상·목표·제3자검증중·수정가능 조건을 보존한다.
- 직원/임원/소속외, 단시간근로자의 내수, 급여 산정범위, 근속연수 단위, 일반직원제도/이사교육을 구분한다. 업종별 원문 기준을 따르고 없는 값을 계산·추정하지 않는다.
- 근거는 인용한 행이 실제 존재하는 페이지 상단 ORIGINAL_PDF_PAGE를 쓰며 하단 인쇄쪽수나 표 시작 페이지를 대체하지 않는다. 여러 페이지의 문장을 한 페이지 인용처럼 합성하지 않는다.

## 검증과 한계

첨부 원본과 재귀 비교하여 description13곳만 달라졌고 그 외 값·키·순서·타입은 모두 동일함을 확인했다. JSON 재파싱 및 기존 실제 녹십자·기업은행·기아 결과의19개 필드/타입 호환성을 확인했다. 기존 실제 Business v5와 업데이트 Finance, 기존 Workforce 결과를 운영 merge_extract_results로 다시 병합하여 각각219/209/186개 사실로 통과했다.

이는 구조 호환성 검증이다. 새 설명을 적용한 원격 Agent는 아직 실행하지 않았다. 중대재해 누락·단위/잠정성 보존·쪽수 오류가 실제 개선됐다는 주장은 적용 후 재실행해야 가능하다. 최소 기아368쪽 중대재해와 직원표333쪽, 녹십자498~499쪽 환경표를 재확인한다. 녹십자의 기존 평가 응답은 서버 캐시 결과였다. 최종 기업브리프 Agent는 호출하지 않았다.

운영 코드·.env·원본 첨부 파일은 변경하지 않았다.
