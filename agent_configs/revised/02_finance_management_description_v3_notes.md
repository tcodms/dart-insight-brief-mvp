# Finance Management description v3

원본: 사용자가 첨부한 DART Finance Management Extract Agent.json.

## 변경 범위

원본의 description 문자열 17곳만 수정했다. 기존 23개 필드의 이름·순서·타입, 배열 항목 타입, 메타데이터, Agent/config 식별자, workflow 설정, schemaLayout, 문서 파싱 설정은 원본과 동일하다. 원본 파일·.env·실행 코드는 수정하지 않았다. export 메타데이터도 그대로이므로 기존 Agent ID가 보존된 것은 원본 유지의 결과이며 현재 서비스 연결값을 변경한 것은 아니다.

## 범용성 판단과 보완

기존 공통 필드와 industry_specific_metrics를 통해 여러 업종을 표현할 수 있다. 녹십자·기업은행·기아의 이전 실제 응답에서는 핵심 지표 추출과 Python 병합이 가능했다. 다만 이 세 기업만으로 모든 업종의 신뢰도를 보증할 수는 없다. 수정본은 제조·제약·유통·서비스·플랫폼·건설·은행·보험의 원문 지표를 수용하고 없는 지표를 억지로 만들지 않도록 설명했다.

- 표 머리글/주석의 천USD·천CNY·백만원 등 배율을 각 사실 및 근거에도 보존한다. 보증잔액·한도·통화별 합계를 구분한다.
- 연결/별도·전체/부문·신탁 포함/제외·지배주주/전체·기간을 구분한다.
- 표와 본문의 부호/증감이 상충하면 모순된 원인을 확정하지 않고 limitations에 기록한다.
- 현금 증가/감소 요인과 공식 활동별 현금흐름을 구분하고 수익성·건전성·자본규제 지표를 업종에 맞춰 추출한다.
- 기존 [E###] 사실, E### | original_page=... | section=... | quote=... 근거, 추세·산업지표 문자열 포맷을 유지한다.

## 확인한 사항

원본과 재귀 비교: 변경 경로는 스키마 description 17곳뿐이며 나머지 값·키·순서·타입은 모두 같다. JSON 재파싱 성공. 기존 세 기업의 실제 Finance 결과는 수정본 23개 필드/타입과 호환되고 운영 merge_extract_results로 실제 Business와 함께 다시 병합하여 각각 151/130/140개 사실로 통과했다(ESG 빈 배치).

이는 구조 호환성 확인이다. 새 설명을 적용한 원격 Agent는 아직 실행하지 않았으므로 단위 오류가 실제 해소되었다는 의미는 아니다. Studio에서 설명을 반영한 버전을 저장하고 서비스에 해당 Agent/config를 연결한 후, 최소 기아 보증표 재실행으로 단위 보존을 확인해야 한다. 최종 기업브리프 Agent까지의 전체 검증도 이번 변경 범위에는 포함하지 않는다.
