# 중간 피드백 반영 확인

2026-10-28 · 계획과 현재 구현을 구분한 점검.

| 피드백 | 현재 상태 | 최종 완료 기준 |
|---|---|---|
| 브리프 각 내용의 원문 위치 표시 | fact의 원본 쪽수·절·인용 저장, 근거 목록과 PDF 페이지 이동 연결. 기존 브리프의 핵심 포인트 일부에는 출처가 있으나 모든 요약·상세 문장과 근거가 연결된 것은 아님 | 브리프의 검증 가능한 사실 항목마다 근거 ID·파일·원본 PDF 쪽수·절·인용을 연결. 내용 옆 출처 버튼으로 해당 위치를 확인. 여러 출처는 모두 표시하고, 없는 출처를 생성하지 않음 |
| 여러 기업의 비교 판단 기준 확정 | 개발 계획 6절에 공통 기준이 있음. 실제 화면은 현재 Markdown 보고서를 나란히 읽는 단계 | 같은 항목을 같은 행에 배치하고, 판단 이유와 양쪽 원문 근거를 확인 가능하게 함. 서로 다른 CV·보고기간·JD 조건 차이를 표시 |

비교의 중심은 **내 CV의 경험을 기업의 사업 방향과 지원 직무에 어떻게 활용할 수 있는가**다. 공통 기준은 기업 사업·전략, JD의 업무·요건, 연결되는 CV 경험, 연결 수준과 이유, 가능한 기여, 부족한 점, 근거다. 비전·인재상은 공식 자료에서 확인될 때만 보조 기준으로 사용하며 미기재는 판단 불가로 표시한다. 기업 순위·합격 가능성 점수는 만들지 않는다.

남은 협업 접점은 상협님 Agent의 구조화된 출력이다. 각 브리프 사실·개인화 판단에 근거 참조를 반환하고 비교 항목의 필드·누락값을 고정해야 한다. 현재 Markdown을 임의 분해하거나 의미가 비슷하다는 이유만으로 사실과 원문을 연결하지 않는다.

검증은 대표 기업 2~3개의 실제 결과로 수행한다. 사실 항목의 출처 연결 누락, 인용문·원본 쪽수 일치, 공통 비교 행의 일관성, CV 차이·JD 없음·비전/인재상 미기재 표시를 확인한다. 이 조건을 충족하기 전에는 두 피드백을 완료했다고 표시하지 않는다.
