# 기여 보고서 핵심 요약 표현 후처리

`pipeline.contribution_wording.polish_contribution_report()`는 핵심 요약 안의 세 소제목과 허용 목록의 정해진 문구만 바꾼다. 자유로운 문장 재작성이나 외부 모델 호출은 하지 않는다.

- 가장 강한 연결 → 활용할 경험
- 준비할 부분 → 보완할 점
- 회사 맥락 → 지원 방향
- 예: 가장 가깝게 연결됩니다 → 관련성이 가장 높습니다

새 Agent 결과는 응답 파싱 후 적용하고, 원시 응답은 기존처럼 별도 보존한다. 저장된 과거 보고서는 DB를 덮어쓰지 않고 조회·다운로드 시 같은 처리를 적용한다. 원래 본문에 연결된 메모가 있는 과거 보고서는 메모의 문자 위치와 버전을 보호하기 위해 원래 표현을 유지한다. 후처리된 화면에서 새로 작성한 메모는 같은 화면을 다시 열어도 유지된다.

핵심 요약 밖의 자기소개서·면접 답변·근거 확인, 인용·코드·링크는 바꾸지 않는다. 수치·미경험·지원 요건을 추론하거나 새로 생성하지 않는다. 기존 CV·JD·기업 FACT와 Agent 입력 스키마는 변경하지 않는다.
