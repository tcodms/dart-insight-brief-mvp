# 멘토 미팅 메모 · 2026-10-29

## 진행 상황

사업보고서의 기업 fact와 CV·JD를 연결해 취업 준비용 기여 보고서를 만드는 서비스입니다. React·FastAPI·SQLite 기반 로그인, PDF 관리, 실제 Agent 실행, 결과 저장·조회·다운로드까지 연결했습니다.

## CV·JD 포함 실제 웹 테스트

녹십자 사업보고서 + 가상 CV + 예시 JD로 기업 브리프·기여 보고서를 생성하고, 다운로드·새로고침 후 재조회까지 확인했습니다. 실제 지원자의 취업 효과까지 검증한 것은 아닙니다.

| 확인 항목 | 결과 |
|---|---|
| 기업·CV·JD 추출 | 주요 재무·인력 정보와 경험·직무 요건은 원문과 일치. 없는 GMP·QMS 실무 경험을 만들지는 않음 |
| 기업 브리프 오류 | 전체 보고부문 매출 합계 2,178,589백만원을 의약품 부문 매출로 잘못 분류 |
| 기여 보고서 오류 | 각각 1쪽인 CV·JD의 출처를 23·24·26쪽으로 표시 |
| 기여 분석의 한계 | 자기소개서 초안에 치우쳐 요구사항별 강점·미경험·자료 부족 설명이 부족 |

## 피드백 반영과 남은 구현

| 항목 | 현재 → 남은 작업 |
|---|---|
| 원문 근거 | 기업 fact의 쪽수·인용과 PDF 이동 연결 → 각 브리프 내용·기여 판단에 출처 연결, 쪽수 오류 수정 |
| 기업·직무 비교 | 보고서 나란히 보기 → 공통 항목 비교표, 입력 조건 차이 표시, 비교 다운로드 |
| Agent 협업 | 기여 결과가 Markdown → 비교용 구조화 JSON·근거 형식·JD 없는 분석 방식 합의 |
| 서비스 구조 | FastAPI·SQLite·LangGraph 실행 흐름 연결 → ChromaDB 검색, 진행·실패 복구, CV·JD 추출 재사용 보완 |
| 운영·검증 | 로컬 실제 분석 확인 → Docker·볼륨·README, 기업 2~3개 비교 및 삭제·실패 상황 검증 |

## Agent를 나눈 이유

- 사업·전략 / 재무·경영 / 인력·조직을 **3개 Agent로 병렬 추출**하고 **기업 브리프 Agent**가 요약합니다.
- **CV·JD Agent**가 경험과 요건을 각각 추출하고 **기여 Agent**가 기업 fact와 연결합니다. 총 **7개**이며, 현재 CV·JD 추출은 순차 실행합니다.
- 영역별 추출과 기업 fact 재사용이 목적입니다. 통합 구성보다 품질·시간·비용이 우수한지는 아직 비교 검증하지 않았습니다.
