# 기여 보고서 원문 연결

기여 보고서의 기업 근거 ID, CV·JD 쪽수 및 근거 필드를 클릭하면 브리프와 같은 근거 패널에서 인용문을 확인하고 해당 문서 PDF를 연다.

- 기업 근거는 연결된 브리프의 원문과 FACT ID를 사용한다.
- CV·JD는 해당 기여 보고서 생성에 사용한 문서 ID와 저장된 추출 결과의 source_page_references를 사용한다.
- 쪽수 없는 근거, 범위 밖 쪽수, 존재하지 않는 추출 항목과 상충하는 중복 참조는 연결하지 않는다. Agent 재호출이나 원문 추정은 하지 않는다.
- 예전 결과에 CV·JD 추출 원본 또는 쪽수 참조가 저장되지 않았다면 해당 링크는 만들지 않는다. 근거 필드 이름을 임의로 다른 문서의 항목과 연결하지 않는다.
- 원문 API의 로그인·소유권 검사를 그대로 사용한다. 기존 보고서 본문과 읽기 메모의 문자 위치는 유지한다.

검증: 후보자 근거 파싱, API의 문서 연결 및 소유권, Markdown의 본문 보존과 클릭, 실제 저장된 결과의 CV·JD·사업보고서 PDF 조회. 별도 브랜치에서 개발하고 main에는 병합하지 않는다.
