# 공동 일일회고 작성 기준

## 대상과 원칙

- 원본 양식: https://docs.google.com/document/d/1VFcLMXxo6u-3gP62isJHKHvqCrYVTvJl83b4WT1w15k/edit
- 작성 기간: 2026-10-26 ~ 2026-11-07. 날짜·작성일은 Asia/Seoul 기준으로 판단한다.
- 문서는 사용자가 직접 입력한다. 에이전트는 복사할 내용만 출력하고 Google 문서를 편집하지 않는다.
- 공동 문서이므로 채은의 해당 작업분만 적는다. 팀원 B/상협 항목, 팀 전체 실적, 멘토 피드백을 추측해서 채우지 않는다.
- 목표·실제 결과는 각각 핵심 1~2개, 체크리스트는 필요 항목 2~3개, 이슈·다음 계획은 보통 각 1개면 충분하다. 이는 분량 가이드이며 개수를 채우기 위한 내용을 만들지 않는다.
- 자연스럽고 짧은 한국어로 작성한다. 내부 파일·함수 이름을 나열하기보다 만든 결과와 사용자에게 생긴 변화를 쓴다.
- 진행률은 사용자가 제공한 값이나 합의된 완료 기준이 없으면 생략한다. 100%를 임의로 쓰지 않는다.
- 산출물은 실제 경로·커밋·URL만 사용한다. 팀원이 열 수 없는 로컬 경로는 로컬 산출물이라고 표시하고 공개 링크처럼 쓰지 않는다.
- 확인하지 않은 테스트 통과·라이브 배포·기능 완성을 주장하지 않는다. 기존 대화 요약만으로 오늘 새로 했다고 쓰지 않는다.

## 실제 양식의 7개 항목

1. 오늘의 목표
2. 오늘 한 일 · 실제 결과물
3. 완료 체크리스트
4. 산출물 · 증빙 (링크 / 스크린샷 / 영상)
5. 이슈 · 막힌 점 & 해결 (이슈 / 원인 / 해결 또는 다음 액션)
6. 협업 분담 (오늘 우선 담당한 작업)
7. 내일(다음 Day) 계획

상단에는 오늘의 마일스톤 제목, 날짜·작성자·자기평가 진행률이 있다.

## 작업 시작에 출력할 내용

해당 마일스톤과 오늘 작업에 필요한 아래 항목만 출력한다. 날짜는 실제 시작일을 쓰고 작성자는 채은의 기여임을 표시한다.

```text
[작업 시작 · YYYY-MM-DD · 손채은 작성분]
오늘의 마일스톤: (이번 작업이 속하는 마일스톤)

① 오늘의 목표
- (오늘 만들 결과 1~2개)

③ 완료 체크리스트 — 예정
- [ ] (확인 가능한 완료 조건)
- [ ] (필요한 검증)

⑥ 협업 분담 — 팀원 A(손채은)
(오늘 담당할 작업 한 문장)
```

작업 시작에는 ②·④·⑤를 미리 완료한 것처럼 작성하지 않는다. 체크리스트는 실제 동작·결과로 확인할 수 있는 수준으로 쓴다.

## 작업 종료에 출력할 내용

발생한 내용이 있는 항목만 짧게 출력한다. 빈 항목과 팀원 B/C 항목을 모두 나열할 필요는 없다. 이슈가 없으면 ⑤를 생략할 수 있다.

```text
[작업 종료 · YYYY-MM-DD · 손채은 작성분]
② 오늘 한 일 · 실제 결과물
- (완료한 핵심 결과)
- (실제 수행한 검증 또는 남은 제한)

③ 완료 체크리스트
- [x] (확인한 완료 조건)
- [ ] (남은 작업이 있으면 표시)

④ 산출물 · 증빙
- (대표 산출물 또는 커밋 1~2개)

⑤ 이슈 · 막힌 점 & 해결
(문제 → 원인 → 조치/다음 액션을 한두 문장으로)

⑥ 협업 분담 — 팀원 A(손채은)
(실제로 담당한 작업 한 문장)

⑦ 내일(다음 Day) 계획
(다음에 가장 먼저 할 일 한 문장)
```

종료 때 시작 목표와 달라졌으면 완료 체크리스트에서 드러낸다. 이미 문서에 있는 ①을 다시 장문으로 덮어쓸 내용을 출력하지 않는다.

## 마일스톤 대응

| 마일스톤 | 회고에 연결할 작업 |
|---|---|
| ① 전환 설계 | 개발 범위·폴더 구조·계획·환경 설정 |
| ② 코어 재구성 | Studio 호출 계층·LLM·임베딩·ChromaDB |
| ③ LLM·SSE | LangGraph·상태·검증 분기·진행 이벤트 |
| ④ 서빙 | 인증·API·저장·Streamlit 연동·실행 흐름 |
| ⑤ 평가·회귀 | 대표 사례·근거·비교 품질·회귀 검증 |
| ⑥ 문서화 | Docker·Compose·패키징·README |

원본 문서의 Day 탭은 10/26~10/31과 11/2~11/6이 확인되었다. 날짜만으로 존재하지 않는 탭이나 제출 완료를 만들어내지 않는다. 마일스톤 산출물의 LMS 제출은 회고 문구 작성과 별개다.
